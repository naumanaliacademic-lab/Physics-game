    Settings

    Without a key, use "Use my Claude app" for AI minutes, or Generate for basic minutes written on the phone. With a key, the transcript is sent to Anthropic's API. The key is saved unencrypted in this app's storage on this device.

    Get a key: sign in at console.anthropic.com, add credit under Billing, then open API keys → Create key and copy it here. A claude.ai subscription doesn't include API use.

    Some Android phones can't record audio and transcribe at the same time. If transcription stops, turn this off.

    Backup

    Meetings are stored only on this device. Save a backup file to keep them safe or move them to another phone. Audio isn't included.
