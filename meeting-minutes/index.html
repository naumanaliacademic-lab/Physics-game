    Without a key the app still writes basic minutes on your phone. With a key, the transcript is sent to Anthropic's API to write full, polished minutes. The key is stored only on this device.

    Get a key: sign in at console.anthropic.com, add credit under Billing, then open API keys → Create key and copy it here. A claude.ai subscription doesn't include API use.

    Some Android phones can't record audio and transcribe at the same time — turn this off if transcription stops working.
